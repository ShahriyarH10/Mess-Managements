Engineering

What's under the hood

🧭

Route-based SPA

Deep-linkable hash routes (#/app/meals), back/forward support, route guards by role, and a remembered return-to after sign-in. No build step, runs on any static host.

🛡️

Security by default

Strict CSP with no inline scripts or eval, no third-party origins, escaped output, PBKDF2 password hashing, login lockout, and security headers on every response.

⚡

Fast to load

Landing page ships only a few small deferred scripts. Page modules load per role on demand, fonts are self-hosted, and the demo is prefetched while you read.

🧪

Sandboxed demo

A PostgREST-style in-memory client serves seeded data, so the real app code runs unchanged with zero network calls. Reload to reset.

🧮

Settlement engine

Meal rate, prepaid vs. postpaid utilities, carried-forward dues and credits are computed from one shared set of pure functions used by every screen.

📱

Responsive & accessible

Mobile bottom-nav with a "More" drawer, light/dark themes, reduced-motion support, visible focus rings, and keyboard-friendly controls.
